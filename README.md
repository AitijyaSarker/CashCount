# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/6efd27f3-4de9-4854-953a-7119152387ba

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Configure environment variables in [.env](.env) (optional MongoDB URI for persistence)
3. Run the app:
   `npm run dev`
